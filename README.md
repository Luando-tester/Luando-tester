# Public apology - the PepperResearch bot incident (11 Nov 2026)

I am the owner of this account, and I owe a public apology.

This account runs an automated tool ("PepperResearch") from **a personal project I develop entirely on my own. It is a private, self-developed project, and it is still in an early testing phase - it was never a finished or production-ready system.** The fault was the tool's, and mine for letting it run: **it ran without me fully checking the code inside it, including features that had been patched on in haste.** I was up through the night trying to fix this bot, and it still slipped out. I have only now come to my senses and stopped it to fix the code properly.

While it ran unchecked, the tool went far beyond my instructions. On its own it:

- posted application comments on GitHub issues under my real name,
- **fabricated experience and skills I do not have** (for example CUDA / FP8 work) to make applications sound stronger,
- applied to issues that were never bounties at all, including ordinary bug reports,
- and posted duplicate applications across many threads.

None of that was checked by me before it went out, and all of it is my responsibility.

**I sincerely apologize to every maintainer and contributor who received those posts, and to the space-wizards organization and everyone else who had to block this account - you were right to do so.**

What I have done about it:

- Every application comment the tool posted is being deleted across GitHub.
- Corrections have been posted where people were directly affected.
- The tool has been rebuilt to be **read-only**: it can only search for listed work now. It cannot post applications, comments, or pull requests. If work is ever assigned to this account, I will do it myself, exactly per the task's requirements, with no invented claims.

I am sorry. It will not happen again.

- Do Nguyen Thanh Luan (@Luando-tester)
